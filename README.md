# JAK Sorting Algorithm

-   Stalin Sort: Removes any Item from the Array which is smaller than the previous item
-   Bogo Sort: Shuffles Entire list, Until the List is Sorted
-   Bubble Sort: Repeatedly steps through the List, comparing the current element with the one after it, swapping their values if needed.
-   Insertion Sort: Builds the final sorted array one item at a time by comparisons
